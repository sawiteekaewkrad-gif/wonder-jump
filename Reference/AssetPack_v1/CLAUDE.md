# Wonder Jump Asset Pack Instructions

When working in this project:
- Read README.md and Documentation/AssetManifest.md first.
- Unity target: Unity 6 LTS, Android only, Landscape.
- Keep all generated assets under Assets/WonderJumpGenerated.
- Do not overwrite source generator files without checking dependencies.
- The current generated character meshes are stylized placeholders, not final rigged models.
- Preserve the six character IDs: Leon, Elin, Miyu, Koko, Riku, Flora.
- Use URP-compatible materials and mobile-friendly geometry.
- Implement gameplay in small tested phases.
- Never claim Android build or multiplayer is tested unless it has actually been built and tested.
